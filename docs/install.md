### Installing Minecraft Raccoon

This is a real NeoForge mod. Drop one jar into the mods folder. No Fabric API, Sinytra Connector, or extra libraries are required.

The previous jar only contained a NeoForge label, so the mods screen listed it and then never ran any raccoon code. Use the new jar below instead of that file.

---

### Prerequisites

- Minecraft `1.21.1`
- NeoForge for `1.21.1` (Enhanced MC / Enhanced Java already includes this)
- Java 21, which that NeoForge version already uses

A mod compiled for one Minecraft version cannot also run on 1.20.4 or 1.21.4. This jar is built for NeoForge `1.21.1` only.

---

### Install

1. Build or copy this jar:
   ```text
   build/libs/minecraft-raccoon-1.1.0.jar
   ```
2. Put that single file in the instance mods folder. For Enhanced MC this is the mods folder of that NeoForge instance, not a Fabric profile.
3. Remove any older `minecraft-raccoon-1.0.0.jar`. Leaving both jars in the folder will conflict.
4. Launch the NeoForge profile.

```text
mods/
└── minecraft-raccoon-1.1.0.jar
```

---

### Creative mode

1. Open a world in Creative.
2. Press `E` and open the Spawn Eggs tab, or search for `Raccoon`.
3. Use the Raccoon Spawn Egg. No crafting is required in Creative.

---

### Survival crafting

Shapeless, in a crafting table:

- 1 Egg
- 1 Sweet Berries
- 1 Bread
- 1 Raw Cod or Raw Salmon

---

### Taming

Right-click a wild raccoon with sweet berries, glow berries, bread, apple, or fish until hearts appear. Right-click with an empty hand to sit or follow. It defends you like a wolf, heals when fed, and two tamed adults can breed.

It walks on all fours, sits when told, and stands on its hind legs when you hold food nearby.
